# АПЕКС АВТО — Многостраничный сайт автосервиса (CMS + CRM)

Полноценное веб-приложение техцентра на **Node.js** + встроенной базе данных **SQLite (`node:sqlite`)** и чистом модульном фронтенде (HTML/CSS/JS) без сторонних зависимостей.

## Основные возможности

- **Многостраничная архитектура:**
  - `/` — Главная страница (Hero с быстрой формой, марки авто, популярные услуги, регламент `01–04`, кейсы, отзывы).
  - `/services` — Полный прайс-лист с категориями, умным поиском и синхронизацией сметы.
  - `/cases` — Выполненные работы с фильтром по узлам и полноэкранным лайтбоксом.
  - `/calculator` — Интерактивный калькулятор ремонта (класс авто, количество осей, копирование и печать сметы).
  - `/booking` — Онлайн-запись с выбором дня/окна, маской телефона, сохранением в SQLite и отправкой в Telegram.
  - `/contacts` — Контакты, интерактивная карта OpenStreetMap и FAQ.
- **Авторизация и роли (`USER` / `ADMIN`):**
  - Безопасное хэширование паролей (`crypto.scryptSync` + соль) и сессии в `HttpOnly`-cookie.
  - `/account` — Личный кабинет клиента: профиль автомобиля, история заявок, актуальные статусы и комментарии мастера.
  - `/admin` — **Админ-панель (CMS + CRM)** с защитой на уровне API: управление заявками, прайс-листом, кейсами (с загрузкой фото), отзывами, FAQ, текстами сайта, Telegram-ботом и ролями пользователей.
- **Светлая и тёмная темы** с сохранением в `localStorage`.

## Быстрый запуск локально

Требуется **Node.js 22.5+** (рекомендуется LTS 24/26):

```bash
npm start
```

Приложение откроется на `http://localhost:3000`. База данных `data/apex.db` создаётся и наполняется автоматически при первом запуске.

### Демо-аккаунты по умолчанию

| Роль | Email | Пароль |
|---|---|---|
| **Клиент (`USER`)** | `client@apex-auto.ru` | `client12345` |

Учётные данные администратора (`/admin`) задаются через переменные окружения `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

## Подключение Telegram-бота

Войдите под администратором (`/admin` → **Настройки и Telegram**), укажите `Bot Token` от `@BotFather` и `Chat ID` от `@userinfobot` и нажмите **Отправить тест в Telegram**. Токен хранится только на сервере и не передаётся в браузер.

Подробная инструкция: [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).
