# Как подключить реальные заявки в Telegram-бота

В проект уже встроена полноценная отправка заявок в Telegram. Вы можете протестировать её локально за 2 минуты, а затем безопасно опубликовать через серверную функцию (Vercel или Netlify).

---

## Шаг 1. Создайте Telegram-бота (1 минута)

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Введите имя бота (например, `Апекс Авто Заявки`) и логин, оканчивающийся на `bot` (например, `apex_auto_leads_bot`).
4. `@BotFather` пришлёт вам **API Token** вида `1234567890:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохраните его.
5. **Обязательно** перейдите в своего нового бота и нажмите кнопку **Start (Запустить)**, иначе бот не сможет писать вам первым.

## Шаг 2. Узнайте свой `Chat ID` (30 секунд)

1. Напишите в Telegram боту **[@userinfobot](https://t.me/userinfobot)** (или отправьте любое сообщение своему новому боту и откройте в браузере ссылку `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`).
2. Скопируйте число из поля `Id` (например, `123456789`).
   - *Если хотите получать заявки в общую группу мастеров:* добавьте бота в группу и возьмите отрицательный `chat_id` группы (начинается с `-100...`).

---

## Шаг 3А. Быстрый тест на своём компьютере (прямо сейчас)

Есть два удобных способа проверить реальную отправку заявок локально:

1. **Прямо на странице сайта:** нажмите кнопку **«⚙️ Настроить Telegram»** в блоке формы заявки, вставьте `Bot Token` и `Chat ID`, нажмите «Сохранить». Данные сохранятся локально в вашем браузере (`localStorage`), и все заявки начнут приходить прямо в ваш Telegram!
2. **Через файл `telegram-config.js`:** откройте `telegram-config.js`, поменяйте `mode: 'direct'` и впишите `botToken` и `chatId`.

> ⚠️ **Важно по безопасности:** режим `direct` подходит только для тестов на вашем компьютере. Не выкладывайте `botToken` в открытый доступ (например, на GitHub), иначе кто угодно сможет писать от имени вашего бота.

---

## Шаг 3Б. Безопасный запуск в интернете (Vercel / Netlify)

Для реального сайта уже готовы серверные функции, которые скрывают токен бота от браузера:
- Для **Vercel**: `api/send-telegram.js`
- Для **Netlify**: `netlify/functions/send-telegram.js`

Как включить:
1. В файле `telegram-config.js` установите:
   ```js
   window.TELEGRAM_CONFIG = {
     mode: 'serverless',
     serverlessEndpoint: '/api/send-telegram', // или '/.netlify/functions/send-telegram' для Netlify
     botToken: '',
     chatId: '',
   };
   ```
2. Залейте проект на Vercel или Netlify.
3. В настройках проекта на хостинге (**Environment Variables**) добавьте две переменные:
   - `TELEGRAM_BOT_TOKEN` = ваш токен от `@BotFather`
   - `TELEGRAM_CHAT_ID` = ваш `Chat ID`
4. Пересоберите/переопубликуйте проект — готово! Заявки будут уходить через сервер, а токен останется полностью защищён.
